# Open Design Catalog Attribution

Vini Canvas imports the Open Design skills and design-systems catalog as read-only guidance content.

- Source: https://github.com/nexu-io/open-design
- Imported commit: 33f2ee58a81fc1131f24c307ce9975f3c00f45da
- License: Apache-2.0
- Imported skills: 133
- Imported design systems: 150

The catalog is not a separate app, sidecar runtime, or trusted executable dependency. It is used to select design/workflow context for Vini Canvas prompts.
