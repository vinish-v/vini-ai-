### host_file_import
Import a real Windows host file into Vini AI's local runtime workspace.
Use this for DOCX/XLSX/PPTX before editing in Vini Desktop/LibreOffice.
The host path must be inside a scoped folder. Large files and denied/out-of-scope access must be reported honestly.

Args: `host_path`, optional `local_path`, `register_office`, `open_in_desktop`
