### host_office_open
Open a scoped Windows host Office file in Microsoft Word, Excel, or PowerPoint.
Use only when the user explicitly asks for native Microsoft Office. For normal visible in-app Office work, import the file and use Vini Desktop/LibreOffice.
This opens on the Windows desktop, not inside Vini's in-app live computer view, and requires approval.

Args: `path`, optional `app` (`word`, `excel`, `powerpoint`)
